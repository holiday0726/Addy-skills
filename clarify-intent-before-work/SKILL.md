# 시작하기 전에 의도 분명히 하기

예전에는 모호하게 부탁하면 누군가 되물었다.
그 질문을 받고서야 내 생각이 정리되지 않았다는 것을 알았다.
에이전트는 대개 되묻지 않는다.
빈 곳을 스스로 채워 완성된 것처럼 보이는 결과를 돌려준다.
그 밑의 생각이 여전히 흐린데도 그렇다.

이렇게 쌓이는 것이 의도 부채다.
결과물 안에 숨은 목표, 제약, 근거가 내 것이 아닌 상태다.
의도는 사람에게서 나와야 하고, 다른 누구도 대신 채워 주지 못한다.

## 1. 가설을 먼저 적는다

에이전트를 돌리기 전에 답이 무엇일지 적는다.
엉성한 추측이어도 된다.
잘 쓰인 답을 한 번 읽고 나면 다른 가능성을 떠올리기 어렵기 때문이다.

실마리가 전혀 없으면 사각지대 점검을 먼저 맡긴다.
내가 아는 것을 주고, 내가 모르는 줄도 모르는 것을 찾아 달라고 한다.

## 2. 도움인지 대신인지 정한다

생각을 도와 달라는 것인지, 생각을 대신해 달라는 것인지 정한다.
둘 다 괜찮다.
어느 쪽인지 알고 맡기면 된다.
결과를 다른 사람이 감당하는 일이면 도움 쪽으로 둔다.

## 3. 흐리면 인터뷰한다

브리프를 내 말로 쓸 수 없으면 의도가 아직 흐린 것이다.
이때는 바로 맡기지 않고, 에이전트가 사용자를 인터뷰하게 한다.

- 에이전트는 이해되지 않는 곳을 한 번에 두세 개씩 묻는다.
- 묻는 대상은 목표, 쓰는 사람, 범위 밖, 끝났다고 볼 기준, 결과가 틀리면 누가 무엇을 감당하는지다.
- 사용자의 답을 받으면 에이전트가 브리프 초안을 고쳐 보여 주고, 아직 빈 칸을 다시 묻는다.
- 브리프의 모든 칸을 사용자가 자기 말로 채울 수 있으면 인터뷰를 끝낸다.

좋은 인터뷰는 선순환을 만든다.
질문이 요청을 날카롭게 하고, 요청이 결과를 날카롭게 하고, 결과가 다음 질문과 사용자의 이해를 날카롭게 한다.
세션을 마칠 때 사용자의 생각이 더 또렷해졌다면 성공이다.

## 4. 브리프를 쓴다

```
목표: 이 일이 끝나면 무엇이 달라지는가
내 가설: 결과가 어떨 것이라고 보는가
대상: 누가 이 결과를 쓰는가
범위 밖: 하지 말 것, 건드리지 말 것
완료 정의: 어떤 명령, 테스트, 측정값이 나와야 끝인가
스스로 확인할 수단: 에이전트가 직접 돌려 볼 테스트, 실행 명령, 화면 확인
원본: 읽어야 할 원본 문서와 데이터 경로
받을 보고: 증명한 것, 증명하지 않은 것, 혼자 정한 결정과 가정, 결정이 필요한 것
```

칸마다 이유가 있다.

- **완료 정의**를 미리 정하지 않으면, 끝난 뒤 어떤 결과든 합리화하게 된다.
- **스스로 확인할 수단**을 주면 에이전트가 고치고, 돌리고, 결과를 읽고, 다시 고치는 일을 내가 보기 전에 끝낸다. 자세한 것은 verification-loop 스킬에 있다.
- **원본**을 넘기지 않으면, 에이전트끼리 요약만 넘기다가 세 번째 에이전트는 원본을 읽지 않은 상태가 된다.
- **받을 보고**를 미리 요구하지 않으면, "다 잘 됐다"는 요약에 에이전트가 대신 내린 결정이 묻힌다.

## 5. 맡기기 전에 한 번 더 본다

- **여력.** 받아서 검토할 수 있는 양보다 많이 맡기고 있지 않은가. 그렇다면 일을 늘리지 말고 체크를 강화하거나 속도를 줄인다.
- **위험도.** 되돌리기 쉬운 일은 브리프를 짧게 쓴다. 운영 반영, 삭제, 돈, 다른 사람이 결과를 감당하는 일은 모든 칸을 채운다.

## 두 번 고쳐도 안 되면

두 번째 수정 요청으로도 원하는 곳에 닿지 않으면 땜질을 멈춘다.
브리프를 처음부터 다시 쓴다.
대개 목표나 완료 정의가 흐렸던 것이다.
필요하면 3번 인터뷰로 돌아간다.

## 내보내는 글

이 스킬이 만드는 것은 사람이 읽는 글이다.
그래서 아래를 기본으로 지킨다.

- humanizer 스킬이 있으면 결과 글에 적용한다.
- 가운뎃점, 줄표(긴 것과 짧은 것), 화살표 기호를 쓰지 않는다.
- 하이픈으로 두 낱말을 잇지 않는다.
  ID, 경로, URL, 명령, 코드, 브랜치 이름처럼 원래 하이픈이 든 값만 그대로 둔다.
- 문장이 끝나면 줄을 바꾼다.
- 조어식 제목, 일상어 자리의 비유, 짜맞춘 대구, 아무도 하지 않은 말을 부정하며 시작하는 대조, 과장, 앞 문장을 되풀이하는 맺음을 쓰지 않는다.
- 다 쓴 뒤 금지 문자가 남았는지 검사한다.

```bash
# 가운뎃점, 줄표, 화살표
grep -nP '[\x{00B7}\x{2010}-\x{2015}\x{2190}-\x{21FF}]' <파일>
# 낱말을 잇는 하이픈
grep -nP '[가-힣A-Za-z]-[가-힣A-Za-z]' <파일>
```

두 번째 검사에 걸린 줄 가운데 ID, 경로, URL, 명령, 코드, 브랜치 이름만 남기고 나머지는 고친다.
