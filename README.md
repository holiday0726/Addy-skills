# Addy-skills

Addy Osmani 의 글을 바탕으로 만든 에이전트 스킬 모음입니다.

## 스킬

| 스킬 | 언제 쓰나 |
|---|---|
| [critical-thinking-with-agents](critical-thinking-with-agents/SKILL.md) | 에이전트에게 일을 맡길 때, 내 일을 끝낼 때, 사람의 큰 결정을 도울 때 |

## 설치

Claude Code 에서 쓰려면 스킬 폴더를 스킬 경로에 넣습니다.

```bash
git clone https://github.com/holiday0726/Addy-skills.git
cp -r Addy-skills/critical-thinking-with-agents ~/.claude/skills/
```

프로젝트에만 넣으려면 `~/.claude/skills/` 대신 프로젝트의 `.claude/skills/` 에 복사합니다.
